# Race Track Car Simulation

This project is designed to practice Java's Object-Oriented Programming (OOP) fundamentals.  
By creating two classes, `Car` and `RaceTrack`, this simulation allows a car to drive and consume battery power  
while checking if it can complete the track based on its distance and battery status.

## Technologies Used
- Java 17
- Object-Oriented Programming (OOP)

## Main Features
- The `Car` object drives based on its speed and battery drain. If the battery is too low, it stops.
- The `RaceTrack` object checks if the car can finish the specified distance using a loop-based simulation.

## Learning Points
- Understanding and applying Java classes and objects in an OOP context.
- Using `while` loops for condition-based simulation.
- Logical flow control using `boolean` and `if` statements.
- Abstracting real-world behavior (driving and battery consumption) into class design.
