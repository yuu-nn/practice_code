# Football Position Finder

This is a simple Java program created to practice `switch expressions`,  
a feature introduced in Java 14 and above.  
The program returns a football position based on a given uniform number.

## Technologies Used
- Java 17
- Switch Expression

## Features
- The program uses hardcoded uniform numbers to demonstrate position output.
- If the uniform number matches a known player → Returns the position.
- If the uniform number is not recognized → Outputs `"unknown"`.

## Example Output
striker
unknown

## Learning Points
- Multi-case labels in `switch expressions`.
- Arrow case(->) labels.
- Using `switch` as an expression to return a value.
