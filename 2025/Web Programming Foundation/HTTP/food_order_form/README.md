# Food Order Form Example
This project is a simple HTML5-based order form designed to practice various form input elements.
Users can enter personal information, choose menu items, drinks, pick-up time, and add special requests before submitting their order.

## Learning Points
-Using the form tag for data submission (method="get")
-Practicing various input types: input, select, radio, checkbox
-Implementing autocomplete menus with datalist
-Using textarea for multi-line user input
-Adding a marketing consent checkbox for personal data collection

## Example
Open food_order_form.html in a web browser to see the order form.
After filling it out and clicking [Submit], the entered data will appear in the URL query string
since the form uses the GET method (In this code, no backend processing).
