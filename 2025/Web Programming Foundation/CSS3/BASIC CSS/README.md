# Selector practice
이 코드는 css를 처음 익힐 때 배우는 **선택자**에 대한 실습 코드입니다. 

## Learning Points
-HTML 문서 내부에 스타일 시트를 작성하는 법을 익혔습니다.
-body에 쓴 내용을 style 태그로 불러와 직접 디자인을 넣는 법을 익혔습니다.
-전체 선택자, 태그 선택자, 아이디 선택자, 클래스 선택자, 후손 선택자 등 다양한 선택자를 실습해 볼 수 있었습니다.
-제가 원하는 색과 조합으로 웹 사이트를 꾸밀 수 있었습니다.
