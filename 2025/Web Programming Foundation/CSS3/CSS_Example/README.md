# COFFEE
가상의 커피 브랜드의 홈페이지를 구현한 html 실습 코드입니다.  
특히 **CSS의 시각적 요소들을 직접 실습해 볼 수 있는 예제**입니다.

## Learning Points
- HTML 문서 내부에 스타일 시트를 작성하는 기본적인 기능들을 익혔습니다.  
- 색깔과 투명도, 박스 크기를 정하거나 그림자 기능 등, 시각적인 기능들을 익혔습니다.
- 네비게이션 바, 카드 스타일 박스, 수평선, 강조 박스 등 다양한 레이아웃을 구현해 보았습니다.  
- 이미지와 텍스트를 조합하여 실제 서비스와 비슷한 레이아웃을 구성하는 법을 익혔습니다.
- 스크롤을 내려도 계속 따라붙는 고정 바를 구현해 보았습니다.

# Technologies Used
CSS3 , HTML5

## Key Features
- 상단 네비게이션 바 구현  
- 주목도 높은 이벤트 배너(`FIRE SALE!!`)와 반투명 강조 영역  
- 커피 상품 정보 카드 UI 구성  
- 하단 푸터와 저작권 정보 표시  
- 커피잔 일러스트 이미지 배치
- 고정 바 배치

  
---
이 실습을 통해 단순한 텍스트 중심의 HTML에서 벗어나, 디자인 까지 입히는 CSS에 대해 더 자세히 알 수 있었습니다.   
기존에 HTML만을 이용해서 웹을 구현할때보다 웹이 한눈에 들어오는 느낌이 들 시각적인 요소도 매우 중요함을 느꼈습니다.
