# cookie

## 문제 링크
https://dreamhack.io/wargame/challenges/6

## 문제 설명
쿠키로 인증 상태를 관리하는 간단한 로그인 서비스다.
admin 계정으로 로그인에 성공하면 플래그를 획득할 수 있다.

## 풀이과정
1. 제시된 파이썬 코드에서
users = {
    'guest': 'guest',
    'admin': FLAG
}
코드를 찾았다. guest의 비밀번호가 guest인것을 확인하고 로그인을 진행하였더니 로그인이 되었다.
2. guset로 로그인 된 상태의 쿠키값을 확인해보니 값이 guset였다.
3. admin의 쿠키값은 admin일까 생각하고 쿠키값을 admin으로 바꿔줬더니 플래그를 찾을 수 있었다.

## 배운점
쿠키값만으로 쉽게 로그인에 성공할 수 있음을 배웠다. guest의 쿠키값이 guset인 것을 보고 admin또한 그렇게 적용해서 문제가 풀리는 것을 통해 웹 해킹에는 내가 파이썬 코드를 읽고 직접 분석하는 것도 중요하지만, 어느정도의 감 또한 필요하다고 느꼈다.
