# game
이 코드는 스타크래프트 스타일의 간단한 전략 게임 시뮬레이션을 파이썬으로 구현한 예제입니다.
- 기본 유닛(Unit)을 상속받아 공격 유닛(AttackUnit), 보병(Soldier), 탱크(Tank), 전투기(Stealth) 등 다양한 유닛 클래스를 정의했습니다.
- 각 유닛은 이동(move), 공격(attack), 피해(damaged) 기능을 가지고 있으며, 탱크는 시지 모드(공격력 강화), 전투기는 은폐 모드(은폐 기능)를 사용할 수 있습니다.
- 비행 기능을 담당하는 Flyable 클래스를 다중 상속해 공중 유닛을 구현하였고, 유닛들의 특성에 맞게 메서드를 오버라이딩 하였습니다.
- 게임 시작과 종료를 알리고, 여러 유닛을 생성하여 일괄 관리하며 전투 시뮬레이션을 진행합니다.

## Technologies Used
- python
- 객체 지향 프로그래밍(OOP): 클래스, 상속, 다중 상속, 메서드 오버라이딩
- 랜덤 모듈(random): 전군 피해량을 무작위로 설정
- 기본 입출력(print): 게임 진행 메시지 출력

## Main Features
- **유닛 생성**: 보병, 탱크, 전투기 등 다양한 유닛 인스턴스 생성  
- **유닛 이동**: 지상 유닛과 비행 유닛 각각 이동 방식 구현  
- **공격 기능**: 유닛별 공격력과 위치 지정 공격  
- **피해 처리**: 피해량 계산 및 체력 관리, 유닛 파괴 여부 출력  
- **특수 기능**:  
  - 탱크의 시지 모드 (공격력 2배 증가, 이동 불가)  
  - 보병의 강화제 사용 (HP 감소 조건부 능력 사용)  
  - 전투기의 은폐 모드 토글  
- **게임 진행 시뮬레이션**: 게임 시작/종료 알림, 모든 유닛 일괄 이동, 특수 기능 활성화, 공격 및 피해 처리

## Learning Points
1. **객체 지향 프로그래밍 (OOP) 기초를 이해했습니다.**  
   - 클래스와 객체 생성, 인스턴스 변수 초기화(`__init__`)를 구현했습니다.  
   - 상속을 통해 기능 확장과 코드 재사용을 했습니다.  
   - 부모 클래스 메서드를 호출하고 오버라이딩했습니다.

2. **다중 상속(Multiple Inheritance)을 적용했습니다.**  
   - `AttackUnit`과 `Flyable`을 동시에 상속해 공중 유닛을 구현했습니다.  
   - 다중 상속 시 생성자 호출과 메서드 오버라이딩 방법을 익혔습니다.

3. **클래스 변수와 인스턴스 변수의 차이를 이해했습니다.**  
   - `siege_developed` 같은 클래스 변수를 사용해 여러 인스턴스가 상태를 공유하게 했습니다.

4. **객체 상태에 따라 동작을 조건 처리했습니다.**  
   - 탱크의 시지 모드 전환 및 해제, 보병의 강화제 사용 제한 등 상태에 따른 기능 분기를 구현했습니다.

5. **유닛을 리스트로 관리하며 반복 처리했습니다.**  
   - 여러 객체를 리스트에 넣어 이동, 공격, 피해 등 일괄 처리를 했습니다.  
   - `isinstance`로 타입을 검사하여 특정 동작을 수행했습니다.

6. **랜덤 모듈을 활용해 변동성을 추가했습니다.**  
   - `randint`를 사용해 무작위 피해량을 부여했습니다.

7. **게임 흐름을 함수로 구조화했습니다.**  
   - `game_start()`, `game_over()` 함수를 만들어 게임 시작과 종료를 알렸습니다.
