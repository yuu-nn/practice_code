# tot_avg
이 코드는 네 과목 국어, 영어, 수학, 정보의 점수를 각각 입력받아 총점과 평균을 구하는 간단한 파이썬 프로그램입니다.  
[정올 연산자 - 형성평가 1 #9217] (https://jungol.co.kr/problem/9217?cursor=MTYsMiwxNQ==)

## Technologies Used
- Python  
- 연산자 

## Main Features
- input() 을 활용하여 각 과목별로 점수를 입력받습니다.
- 연산자를 활용하여 총점과 평균을 구합니다.
- 평균은 정수 나눗셈(//)을 통해 소수점 없이 출력합니다.
## Example Output
입력 예시
```
95
78
80
100
```
출력예시
```
tot: 353
avg: 88
```
## Learning Points
- input() 의 활용법을 배웠습니다.
  특히, input()은 기본적으로 문자열(str)을 반환하므로, 숫자를 활용하 싶을 때에는 int(input()) 형식으로 써 줘야 함을 익혔습니다.
- 산술 연산자의 기본 활용을 익힐 수 있는 문제였습니다.
  나눗셈의 몫만 출력하는 연산자(//) 도 익힐 수 있었습니다.
