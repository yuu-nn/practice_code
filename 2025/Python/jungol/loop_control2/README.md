# printN
이 코드는 정수 N을 입력받아서 출력예와 같이 출력하는 간단한 파이썬 프로그램 입니다.  
[정올 반복제어문3 - 형성평가 4 #9344] (https://jungol.co.kr/problem/9344?MTYsNywyMA%3D%3D)

## Technologies Used
- Python  
- 반복 제어

## Main Features
- input() 을 활용하여 정수 N을 입력 받습니다.
- 반복문(for)과 연산자를 활용하여 NxN의 행렬을 출력하는 패턴을 만듭니다. 
- 이때, 알파벳은 z부터, 숫자는 0부터 N-1까지 출력되도록 합니다.

## Example Output
입력 예시
```
3
```
출력예시
```
Z Y X
W V 0
U 1 2
```
## Learning Points
- 반복문을 이용한 패턴 출력 방법을 익혔습니다.
- 제시된 출력 예시를 보고, 패턴을 찾아 코드를 입력하는 법을 익혔습니다.
