# function1
이 코드는 자연수 N과 M을 입력받아서 주사위를 N번 던져서 나온 눈의 합이 M이 나올 수 있는 모든 경우를 출력하는 프로그램입니다.
[함수 3 - 형성평가 3 (4판 형성평가 8) #409] (https://jungol.co.kr/problem/409?&cursor=MywxNiwxNQ%3D%3D)

## Technologies Used
- Python  
- 재귀 함수 (recursive function)
- 조건문 (if)
- 리스트 연산 (+, 인덱스 접근 등)

## Main Features
- `input()`을 통해 두 정수 `N`, `M`을 입력받습니다.
- `dice()` 함수는 재귀 호출을 통해 주사위의 모든 조합을 탐색합니다.
- 현재까지 선택된 주사위 눈은 `sequence` 리스트에 저장됩니다.
- 주사위를 N번 던졌을 때 눈의 총합이 M이 되는 조합만 출력됩니다.
- 각 조합은 공백으로 구분되어 한 줄씩 출력됩니다.

## Example Output
입력 예시
```
3 10
```
출력예시
```
1 3 6
1 4 5
1 5 4
1 6 3
2 2 6
2 3 5
…
6 2 2
6 3 1
```
## Learning Points
- 모든 가능한 해를 탐색하는 방법 중 하나로, 조건을 만족하지 않으면 그 경로를 더 이상 탐색하지 않고 되돌아가는 백트래킹 기법을 활용하여 조건을 만족하는 모든 조합을 탐색하는 방법을 익혔습니다.
- 재귀 함수에 상태 정보를 인자로 넘겨 호출 흐름을 제어하는 방식에 대해 배웠습니다.
- 리스트를 복사하면서 상태를 유지하기 위해 `sequence + [i]`를 사용하는 방법을 익혔습니다.
- 탐색 공간이 커질 수 있으므로 입력 범위에 따라 실행 시간이 늘어날 수 있음을 이해했습니다.
