# printint
이 코드는 정수 N을 입력받아서 출력예와 같이 출력하는 간단한 파이썬 프로그램 입니다.  
[정올 반복제어문3 - 형성평가 1 #9341] (https://jungol.co.kr/problem/9341?=MTYsNywxNw%3D%3D)

## Technologies Used
- Python  
- 반복 제어

## Main Features
- input() 을 활용하여 정수 N을 입력 받습니다.
- 반복문(for)과 연산자를 활용하여 별(*) 출력 패턴을 만듭니다.
- 정수 나눗셈(//)을 사용하여 반복 범위를 계산합니다.

## Example Output
입력 예시
```
3
```
출력예시
```
*
**
***
**
*
```
## Learning Points
- 반복문을 이용한 패턴 출력 방법을 익혔습니다.
- 역순으로 for문을 실행시키고 싶다면 for i in range(N // 2, 0, -1) 과 같은 형식을 이용해야 함을 배웠습니다.
