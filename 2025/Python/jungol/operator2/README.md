# wid_len
이 코드는 사각형의 가로, 세로 길이를 입력받아 가로 길이는 2배하고, 세로 길이는 3 감소시켜서 저장한 후 가로, 세로, 넓이를 차례로 출력하는 파이썬 프로그램 입니다.  
[정올 연산자 - 형성평가 3 #9219] (https://jungol.co.kr/problem/9219?cursor=MTYsMiwxNw%3D%3D) 

## Technologies Used
- Python
- 연산자 (산술 연산자, 복합 대입 연산자)

## Main Features
- input() 을 활용하여 가로와 세로 길이를 입력받습니다.
- 연산자를 활용하여 가로 길이는 2배, 세로 길이는 3 감소시킵니다.
- 가로, 세로, 넓이를 차례대로 출력합니다.

## Example Output
입력 예시
```
15
25
```
출력예시
```
width = 30
length = 22
area = 660
```
