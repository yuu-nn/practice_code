# printcat
영수증에 적힌,
- 구매한 각 물건의 가격과 개수
- 구매한 물건들의 총 금액
  
을 보고, 구매한 물건의 가격과 개수로 계산한 총 금액이 영수증에 적힌 총 금액과 일치하는지 검사해보는 프로그램입니다.

[백준 25304번 문제 - 영수증] (https://www.acmicpc.net/problem/25304)

## Technologies Used
- python
- map
- 조건문
- 반복

## Main Features
- 첫째 줄에는 영수증에 적힌 총 금액 X를 입력합니다.
- 둘째 줄에는 영수증에 적힌 구매한 물건의 종류의 수 N을 입력합니다.
- 이후 N개의 줄에는 각 물건의 가격 a와 개수 b가 공백을 사이에 두고 주어진다.
- 구매한 물건의 가격과 개수로 계산한 총 금액이 영수증에 적힌 총 금액과 일치하면 Yes를 출력한다. 일치하지 않는다면 No를 출력한다.

## Example Output
예시 입력 :  

260000  

4  

20000 5  

30000 2  

10000 6  

5000 8260000

예시 출력 :  

Yes


## Learning Points
- 파이썬에서 쓰이는 if, elif. else 등 조건문의 활용에 대해 배워볼 수 있었습니다.
- 파이썬에서 여러 개의 값에 똑같은 함수를 한 번에 적용해주는 도구인 **map()** 의 활용에 대해 배웠습니다.
- for,while 문 등 파이썬의 반복문에 대해 학습하고 직접 실습해볼 수 있었습니다.
- 별 다른 반복 조건이 없다면 `for _ in range(N):` 을 통해 깔끔하게 N번을 반복하는 코드를 만들 수 있음을 알 수 있었습니다.
