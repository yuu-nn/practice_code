# printcat
두 정수 A와 B가 주어졌을 때, A와 B를 비교하는 프로그램 입니다. 
[백준 1330번 문제 - 두 수 비교하기] (https://www.acmicpc.net/problem/1330)

## Technologies Used
- python
- map
- 조건문

## Main Features
- 두 수, A 와 B 를 한 줄로 입력하면, 결과에 따라 부등호를 출력합니다.

## Example Output
예시 입력 :
1 2
예시 출력 :
<

## Learning Points
- 파이썬에서 쓰이는 if, elif. else 등 조건문의 활용에 대해 배워볼 수 있었습니다.
- 파이썬에서 여러 개의 값에 똑같은 함수를 한 번에 적용해주는 도구인 **map()** 의 활용에 대해 배웠습니다.
