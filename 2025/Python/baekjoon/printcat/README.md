# printcat
이 코드는 고양이 모양을 프린트 하는 간단한 파이썬 코드입니다.  
[백준 10171번 문제 - 고양이] (https://www.acmicpc.net/problem/10171)

## Technologies Used
- python 3
- 이스케이프 처리

## Main Features
- `print` 문을 사용하여 고양이 모양의 ASCII 아트를 출력합니다.

## Learning Points
- 이스케이프 문자 처리 방법을 배울 수 있습니다.  
  특히, `\`는 이스케이프 문자이므로 화면에 출력하려면 `\\`로 작성해야 한다는 점을 학습했습니다.
- 단순한 출력 문제였지만, 완벽한 고양이 그림을 출력하기 위해 공백과 줄바꿈 등의 세부 조정에 주의를 기울여야 했습니다.
