# Student Pointer & Array Practice

이 코드는 포인터와 동적 배열(new[]), 그리고 클래스를 활용해  
학생 정보를 입력받고 출력하는 간단한 실습 프로그램입니다.

## Technologies Used
- C++
- `iostream` 라이브러리
- `class` 및 객체 지향 구조
- 포인터와 동적 배열
- 배열 인덱싱을 통한 객체 접근

## Main Features
- `Student` 클래스는 이름, 학번, 연락처를 저장할 수 있습니다.
- `new Student[3]` 을 사용해 동적 배열을 생성하고,  
  포인터를 통해 각각의 학생 객체에 접근합니다.
- `cin`으로 학생 정보를 입력받고  
  `setInfo()`를 통해 객체에 값을 저장합니다.
- 반복문을 통해 3명의 학생 정보를 입력 → 출력합니다.
- 프로그램 종료 시 `delete[]` 로 동적 메모리를 정리합니다.

## Example Input
[학생 정보 입력]
1번째 학생 이름, 학번, 연락처를 입력하세요: Kim 20240001 010-1111-1111
2번째 학생 이름, 학번, 연락처를 입력하세요: Lee 20240002 010-2222-2222
3번째 학생 이름, 학번, 연락처를 입력하세요: Park 20240003 010-3333-3333
## Example Output
[학생 정보 목록]
이름: Kim, 학번: 20240001, 연락처: 010-1111-1111
이름: Lee, 학번: 20240002, 연락처: 010-2222-2222
이름: Park, 학번: 20240003, 연락처: 010-3333-3333

## Learning Points
- 클래스 객체도 배열 형태로 저장할 수 있다는 것을 알게 되었습니다.
- `new[]`로 생성한 객체 배열을 포인터로 접근하는 방식을 연습할 수 있습니다.
- 반복문과 메서드를 이용해 데이터를 출력할 수 있는 법을 익힐 수 있었습니다.
