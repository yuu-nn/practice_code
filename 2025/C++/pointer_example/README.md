# coutcin
제시된 코드는 C++ 언어를 사용하여 Student 클래스를 정의하고, 이 클래스의 객체들을 배열로 관리하며, 객체 배열과 포인터의 관계를 학습하는 예제입니다.

## Technologies Used
- C++
- 클래스 및 객체
- 배열
- 포인터 


## Main Features
- Student 클래스 정의:
  - 멤버 변수 (name, number, tel)를 **private**으로 설정하여 학생 정보를 캡슐화합니다.
- main 함수 내 객체 배열 생성:
  - Student students[3];을 통해 Student 객체 3개를 저장하는 배열을 선언합니다.
- 배열과 포인터의 관계 학습:
  - Student* p = students;를 통해 배열 이름(students)이 배열의 첫 번째 요소 주소를 가리키는 포인터와 동일함을 보여줍니다.
  - 주석 처리된 부분은 포인터 연산을 사용하여 배열 요소에 접근하고 정보를 설정하는 다양한 방법을 알 수 있었습니다.
    - (p+i)->setInfo(...): 포인터 연산 후 화살표 연산자(->) 사용
    - p[i].setInfo(...): 포인터를 배열처럼 사용
    - (*(p+i)).setInfo(...): 포인터 연산 후 **역참조 연산자(*)**와 점 연산자(.) 사용
- 반복문을 이용한 정보 출력:
  - for 반복문을 사용하여 배열의 모든 요소 (students[0]부터 students[2])의 showInfo() 메서드를 호출하여 정보를 출력합니다.

## Learning Points
- 포인터와 배열의 개념에 대해 학습할 수 있었습니다.
- 클래스 객체를 배열로 선언하여, 여러 객체를 배열로 일괄적으로 관리하고, 반복문을 통해 쉽게 처리하는 방법을 배웠습니다.
- 배열 이름 자체가 c++에서는 첫 번째 요소의 주소를 나타냄을 배웠고, 이를 동일 타입의 포인터 변수로 받을 수 있음을 알 수 있었습니다.
- 포인터를 활용하여 객체의 멤버 함수에 접근할 수 있는 다양한 방법을 알 수 있었습니다.
