# coutcin
이 코드는 사용자로부터 두 개의 정수를 입력받아 그중 더 큰 수를 출력하는 간단한 실습 프로그램입니다. 

## Technologies Used
- C++
- iostream 라이브러리
- namespce std 활용
- if-else 조건문

## Main Features
- **cout**을 사용하여 사용자에게 두 수를 입력하도록 안내합니다.
- **cin**을 사용하여 사용자로부터 두 개의 정수(a와 b)를 입력받습니다.
- if (a > b) 조건문을 사용하여 a가 b보다 큰지 비교합니다.
  - 조건이 참일 경우 (a가 더 큼), a를 출력합니다.
  - 조건이 거짓일 경우 (b가 더 크거나 같음), else 블록이 실행되어 b를 출력합니다.
- 주석으로 삼항 연산자(? :)를 사용한 대체 구현 방법이 제시되어 있습니다.
  
## Example Output
입력 예시
```
두 수를 입력하라 : 15 28
```
출력예시
```
큰 수 =28
```
## Learning Points
- c++의 기본 입출력에 대해 배워볼 수 있었습니다. print를 사용하는 다른 프로그래밍 언어와는 다르게 cout과 cin, >>와 << 를 활용하는 것을 익힐 수 있었습니다.
- 또한 `using namespace std;`를 사용하여 std::cout 대신 cout과 같이 짧게 사용할 수 있음을 알 수 있습니다.
- if-else 조건문을 c++에서 사용하는 법을 알 수 있었습니다.
- 삼항 연산자 (조건 ? 참일 때 값 : 거짓일 때 값)라는 간결한 문법이 있음을 알 수 있으며, 이를 활용하면 더 짧게 코드를 작성할 수 있다는 것을 배웠습니다.
