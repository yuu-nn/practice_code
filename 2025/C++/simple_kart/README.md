# simple_kart
제시된 코드는 C++ 언어를 사용하여 Kart 클래스를 정의하고 이를 객체 지향 프로그래밍(OOP) 방식으로 활용하는 예시입니다. 
카트의 이름, 색상, 속도를 속성으로 가지며, 객체 생성, 정보 출력, 소멸자 등을 구현했습니다.

## Technologies Used
- C++
- 클래스 및 객체
- 생성자 및 소멸자
- 접근 지정자
- 헤더 파일 및 구현 파일 분리

## Main Features
- Kart.h (헤더 파일):
  - Kart 클래스를 선언하며, 멤버 변수 (name, color, speed)는 **private**으로 선언하여 외부 접근을 제한하고 **캡슐화**를 구현합니다.
  - 기본 생성자 (Kart())와 매개변수 있는 생성자 (Kart(string, string, int))를 선언합니다.
  - show() 메서드와 Getter 메서드 (getName(), getColor(), getSpeed())를 **public**으로 선언하여 객체 정보에 접근할 수 있게 합니다.
  - 소멸자 (~Kart())를 선언합니다.
- kart.cpp (구현 파일):
  - 각 생성자는 객체 생성 시 멤버 변수를 초기화합니다.
  - 기본 생성자는 "익명", "검정", 0으로 초기화합니다.
  - 매개변수 있는 생성자는 전달받은 값으로 초기화합니다.
  - show() 메서드는 카트의 모든 정보를 출력합니다. (단, main.cpp에서는 Getter를 사용합니다.)
  - 소멸자는 객체가 메모리에서 해제될 때 (return 0 전) "[카트 이름]을/를 폐차하였습니다."라는 메시지를 출력합니다.
  - Getter 메서드는 각 멤버 변수의 값을 반환합니다.
- main.cpp (실행 파일):
  - Kart 클래스의 객체 세 개 (Kart1, Kart2, Kart3)를 생성하며, 서로 다른 생성자를 사용해 초기화합니다.
  - 각 객체의 Getter 메서드를 사용하여 이름, 색상, 속도를 가져와 출력합니다.

## Learning Points
- 클래스를 만들고, 이를 기반으로 객체를 생성/활용하는 기본적인 객체지향을 이해할 수 있는 실습 코드였습니다.
- private와 public으로 접근 지정자를 나누어 사용하여, 멤버 변수를 보호하는 캡슐화 개념을 익힐 수 있었습니다.
- 객체를 다 이용하였을 때 소멸자를 사용할 수 있음을 배웠습니다. 소멸자는 객체가 생성된 반대로, 즉 가장 최근에 생성된 객체 순으로 호출됨을 알게 되었습니다.
- 클래스를 만든 헤더파일과 실제로 구현하는 파일, 그리고 메인 파일을 분리하여 코드를 체계적으로 관리할 수 있는 모듈화 방식을 익혔습니다.
